MY PROGRESS - IPHONE WEB APP

Files:
- index.html
- manifest.webmanifest

To use on iPhone as a Home Screen app:
1. Put both files on a web host.
2. Open index.html through the hosted address in Safari.
3. Tap Share.
4. Tap Add to Home Screen.
5. Tap Add.

Your entries are stored in the browser on your device. Use Export inside the tracker to make backups.
